# 📊 Power BI Data Modeling Project

## Overview

This project demonstrates the end-to-end process of building a robust Power BI semantic model for sales analytics. Starting with raw transactional data, the project focuses on designing a scalable star schema, creating dimension and fact tables, implementing DAX measures, and securing data using Row-Level Security (RLS).

The project was completed as part of my Power BI learning journey. It provided hands-on experience with data modeling principles commonly used in business intelligence solutions.

---

## Project Objectives

* Transform raw data into an optimized analytical model.
* Design a star schema using fact and dimension tables.
* Create reusable DAX measures for reporting.
* Build a centralized Date table for time intelligence.
* Implement Row-Level Security (RLS) for secure data access.
* Validate relationships and ensure model integrity.
